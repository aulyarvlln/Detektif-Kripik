**Detektif Kripik** merupakan aplikasi permainan investigasi digital yang dikembangkan sebagai proyek akhir mata kuliah Kriptografi.

Dalam permainan ini, pemain berperan sebagai seorang detektif yang bertugas mengungkap kasus melalui berbagai bukti digital yang tersedia. Pemain harus mengumpulkan, memeriksa, dan menganalisis bukti untuk menemukan petunjuk serta menentukan pelaku di balik kasus tersebut.

## Fitur Aplikasi

- **Autentikasi Dongle:** Verifikasi perangkat USB menggunakan tanda tangan digital RSA.
- **Autentikasi Biometrik:** Menggunakan verifikasi sidik jari melalui Windows Biometric API.
- **Dekripsi Dokumen:** Membuka dan membaca dokumen rahasia menggunakan algoritma kriptografi AES-256-GCM.
- **Analisis Audio:** Mengungkap pesan tersembunyi dari rekaman audio.
- **Steganografi Gambar:** Menemukan pesan tersembunyi di dalam gambar menggunakan metode LSB.
- **Rantai Bukti Digital:** Mencatat dan memverifikasi integritas bukti menggunakan hash SHA-256 dan mekanisme blockchain sederhana.
- **Add File:** Memungkinkan pemain menambahkan dan menganalisis file gambar yang mengandung pesan tersembunyi.

## Tujuan

Aplikasi ini bertujuan untuk menerapkan konsep kriptografi, tanda tangan digital, steganografi, dan integritas data dalam bentuk permainan investigasi yang interaktif dan menarik.
